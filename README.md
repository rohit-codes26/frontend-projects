Modern Image Gallery

A modern and responsive Image Gallery web application built using HTML, CSS, and JavaScript. This project features a stylish Pinterest-style masonry layout with dark/light mode, image filtering, live search, hover animations, and fullscreen lightbox preview.

✨ Features
Responsive Masonry Grid Layout
Dark & Light Theme Toggle
Category Filter System
Live Image Search
Fullscreen Lightbox Preview
Smooth Hover Animations
Modern Glassmorphism UI
Mobile Friendly Design
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Font Awesome Icons
